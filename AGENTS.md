## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `saethor/varda`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context (monorepo): root `GLOSSARY-MAP.md` points to a `GLOSSARY.md` per package; system-wide ADRs in `docs/adr/`, package-specific ADRs alongside each package. See `docs/agents/domain.md`.
