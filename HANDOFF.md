## The project in brief

A training diary and planning tool, mostly for running with strength alongside, built around the **athlete–coach relationship** (an athlete can be their own coach, and can have any number of external coaches). Training is modelled as a **journey**: stones are placed one at a time on the way to a destination. **No code has been written yet** and no tech stack has been chosen.

## History not recorded elsewhere

- **Naming:** the first shortlist was Pacelab, Splitsmith, Sleipnir and KM0. **Pacelab was rejected** (no "lab" or science themes). **Sleipnir was rejected** as "not me" (avoid heavy mythology). KM0's journey idea led to **Varða**; Splitsmith became the name of the planning side.
- **Logo:** rejected along the way, so don't re-propose: a B cairn with more stone character, cairns built from many small rocks, the ð in color, a serif wordmark, stones in the A crossbars. The user wants it **calm, with a single accent**.
- **Vocabulary:** Icelandic words were first meant for the UI only; the user then asked for the theme to be carried into English, and later for ambiguous terms to be prefixed (Workout outcome, Workout step, Repeat block, Step target, Journal comment/reaction, Strength exercise/set).

## Practical notes

- `rsvg-convert` and ImageMagick are **not installed**. To check SVG/HTML visually, use headless Chrome and Read the PNG:
  ```
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
    --hide-scrollbars --screenshot=/tmp/out.png --window-size=1300,1100 "file://$PWD/<file>.html"
  ```
- The logo SVGs are generated by `.venv/bin/python logo/build/build_logo.py` (needs fonttools in `.venv/`).
